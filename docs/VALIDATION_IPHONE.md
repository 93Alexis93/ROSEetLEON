# Validation manuelle sur iPhone

Cette liste complète les tests automatisés. Cocher les points uniquement après les avoir réellement essayés sur l’appareil.

## Parcours de Rose
- [ ] Ouvrir l’application dans Safari et entrer dans l’univers de Rose.
- [ ] Lancer successivement couleurs, formes, lettres, sons des lettres, majuscules/minuscules, suites et syllabes.
- [ ] Pour chaque activité à choix : répondre juste, vérifier le bravo vocal et visible, puis toucher « Question suivante ».
- [ ] Vérifier que l’image et les choix de la nouvelle question apparaissent et que les anciens choix sont désactivés.
- [ ] Terminer une série complète et vérifier le message de récompense final.
- [ ] Répondre faux une fois puis deux fois : vérifier l’aide douce, la réponse expliquée et la possibilité de continuer.

## Parcours de Léon
- [ ] Ouvrir les maths, le nombre mystère, les suites, la lecture et le calcul mental.
- [ ] Vérifier indices, erreurs, bonne réponse, progression et fin de partie.
- [ ] Vérifier qu’une activité ne répète pas une question dans la même série lorsque cette diversité est prévue.

## Voix, sons et accessibilité
- [ ] Répéter le test avec la voix activée puis désactivée.
- [ ] Répéter avec les sons activés puis désactivés.
- [ ] Vérifier qu’aucun ancien bravo n’est lu après le passage à la question suivante.
- [ ] Vérifier les grandes cibles tactiles, le défilement et le retour à l’accueil.
- [ ] Si possible, tester VoiceOver et la préférence iOS de réduction des animations.

## Mode hors ligne et mise à jour
- [ ] Charger l’application une première fois en HTTPS et ouvrir au moins une activité.
- [ ] Activer le mode avion, fermer puis rouvrir l’application installée ; vérifier que l’accueil, les styles, scripts et icônes chargent.
- [ ] Après une nouvelle version, reconnecter l’iPhone, ouvrir l’application et vérifier que la nouvelle version est bien récupérée.

## Impression A4
- [ ] Dans l’espace parent, imprimer une fiche seule.
- [ ] Imprimer une fiche avec son corrigé.
- [ ] Vérifier l’aperçu A4, les marges, les sauts de page, les calculs et l’absence de page blanche.
- [ ] Vérifier que les boutons de navigation et commandes inutiles ne sont pas imprimés.

## Résultat
- Date et appareil : à compléter.
- Version / commit testé : à compléter.
- Résultat et anomalies : à compléter.

Ne pas déclarer cette validation terminée sur la seule base des tests GitHub Actions.
