# Rose & Léon
Application familiale éducative, locale et hors ligne, conçue pour Safari sur iPhone.

## Installation iPhone
Ouvrir l'URL GitHub Pages dans Safari → Partager → Sur l'écran d'accueil → Ajouter.

## GitHub Pages
Dans le dépôt : Settings → Pages → Build and deployment : Deploy from a branch → branche `main`, dossier `/(root)` → Save. URL attendue : https://93Alexis93.github.io/ROSEetLEON/.

## Confidentialité
Données stockées dans le navigateur. Aucun compte, serveur applicatif, CDN, traceur ni publicité. Exporter régulièrement la sauvegarde JSON depuis l'espace parent.

## Technique
HTML, CSS et JavaScript natifs en modules ES. Aucun build ni dépendance npm. Jeux : maths, lecture, anglais oral, aventures, robot programmeur et fiches A4. Hors ligne après un premier chargement HTTPS.
